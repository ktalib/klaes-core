KLAES · Cadastral Department · step 8

Charting Card

The small card AD Cad Report (and, for Direct files, AD Cad Info) fills in after charting a file on the sheet. Charting on the sheet stays outside KLAES; this card records the result. Each card gets a charting number, and the charting table lists every card by that number. Please mark each field below as keep, change or remove, and answer the questions at the end. Nothing is built until this is agreed.

3 · Please answer

Questions for the client

Q1 · fieldsWhich of the fields above are needed? Is anything missing from the paper card you use today?
Q2 · existing plotWhen the file falls on an existing plot, what happens next: does it stop, go back to D Cad, or carry on with a note?
Q3 · not chartedIf a record cannot be charted, can the file still move on, or must it go back?
Q4 · coordinatesAre beacon coordinates written on the card today? Which coordinate system: UTM Zone 32N on the Minna datum?
Q5 · sheetsWhich sheet references do you record: metric index, imperial sheet, or both?
Q6 · 2nd chartingFor Direct files, does the 2nd charting just confirm the 1st, or re-record everything?
Q7 · charting numberIs "CH-2026-00001" fine, or do you already number charts a certain way?
Q8 · printShould the card print (for the file jacket), like the File Movement Card?

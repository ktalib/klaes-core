Cadastral Department Workflow

How a file moves through Cadastral, desk by desk, after the client walk-through on 10 October. It covers the three application types, the action menus each desk gets, which old screens are reused, and the order we build in.

1 · Routes

The three workflows

Each column is a phase. Each card is one stop of the main file, with the desk on top. Dashed cards are other departments. Decision cards show the question the officer answers; the answer picks the next desk.

Registry

  • Register (existing Intake Queue form) · sends to D Cad automatically, row locks
  • Send back to source · only after “Not recommended”
  • Detach correspondence file → Send to Director Land
  • Receive back · Attach correspondence file
  • Send to Deeds · last action; checks FMC, charting, correspondence file, bill
  • Return to requester · Verification

D Cad

  • Recommend / Not recommend · same line; Recommend pops up “Send to DD Cad”
  • Within the 10 km buffer? → KAMMA / Physical Planning
  • Send to Cadastral Information
  • Send to DD Cad (survey stage)

DD Cad

  • Recommend → Send to AD Cad Info
  • Not recommend → back to D Cad, with reason
  • Send to AD P&D (survey stage)

Cadastral Information

  • Commission FMC (prints with QR)
  • Check layout plan · 1st charting · Direct only
  • Send to Cadastral Report / D Cad / DD Cad
  • FMC updates are automatic, so there is no “update” action

Cadastral Report

  • Charting card + charting number
  • Land 12 · Yes/No form · link to existing, to confirm
  • Create Correspondence File
  • Send to Compensation / Director Land · by type

AD P&D

  • Commission Field Jacket (creates job, locks surveyor)
  • Reassign surveyor
  • Issue I to S
  • Generate Fees P&D bill (no payment)
  • Send to AD Cadastral

5 · Brief

What the client decided

TopicDecision
Intake typesConversion: conversion file, Quarry, SIT, DCIV. Direct: GKN, Misc KN, DCIV, OP (OP → Resettlement or Direct Allocation). Verification: any file type.
RegistrationReuse the Intake Queue. File must already be indexed or commissioned. Duplicate = same file number already taken in.
File sourceLand, DCIV, Survey, SLTR, Sectional Titling, … “Not recommended” returns it there.
Hand-offRegistering sends to D Cad. Registry row is view-only until it comes back.
DD Cad refusalBack to D Cad with a reason (the document said Registry).
Short formsD Cad, DD Cad, AD Cad Info, AD Cad Report, AD P&D, FMC.
FMCQR issued at commissioning. Header: name, file title, file number, location, district, block no., date/time. Log: unit, reason, date/time, officer. Automatic.
ChartingSheet charting stays outside KLAES. Card + charting number in KLAES. Direct: 1st under Information, 2nd under Report.
Compensation“Falls on Government acquisition?” Yes → rejected, back. No → DSG → D Cad.
BufferD Cad checks on GIS. “Within 10 km of the town centre?” Yes → KAMMA, No → Physical Planning.
BillOne Fees P&D bill, no payment. Surveyor mobile app backfills field data later.
RecommendationsPlain yes/no, not the brief-recommendation letters.
VerificationIntake switches to “search correspondence file” and shows the match.
6 · Open

Answered and still open

Answered · Direct routingGKN, Misc KN and DCIV files that are not OP take the Direct Allocation path: straight to Director Land, skipping Compensation. OP files still choose Resettlement or Direct Allocation.
Answered · DD Cad returnThe file goes back to D Cad with DD Cad's reason, and D Cad decides again: recommend once more, or not recommend (Registry, then back to source).
Answered · peopleNormal users. Whoever is given a desk's sidebar entry in user roles can act at that desk.
To confirm · outside departmentsYour view: they get their own screens. The recording only clearly says this for the Compensation Unit (“to be harmonised”). The others log the file in and out with the FMC QR code.
Asst. Director CadastralAt the end, the bill passes from AD P&D to “Asst. Director Cadastral”, then Registry. Is that another officer with their own screen, or one of the three ADs already listed?
Record SectionFor Direct files, AD P&D sends the file to the Record Section to attach the survey plan. Do they need a screen in KLAES, or does AD P&D just tick “survey plan attached”?
DetailsCharting card fields (client edits the draft), Land 12 link, field-jacket and job number formats.

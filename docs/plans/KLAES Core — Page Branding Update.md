KLAES Core — Page Branding Update
Purpose
Update the visible KLAES interface to reflect the new KLAES Core identity.

This task is branding/UI only for now.

Do not implement the full KLAES 2.0 module architecture yet. Do not change workflows, database logic, routes, permissions, or business processes.

Pages to Update
1. Login Page
Update the current KLAES login page branding.

Required changes
Replace the main visible KLAES branding with KLAES CORE
Add the new KLAES Core logo
Update the page title/browser title if it currently says only KLAES
Update any subtitle/tagline directly attached to the login branding
Keep the existing login form and authentication behavior unchanged
Suggested display
KLAES CORE

Optional supporting text:

Part of the KLAES 2.0 Suite

2. Welcome / Splash Screen
Update the current welcome/splash screen shown when entering the system.

Required changes
Replace the old KLAES logo with the new KLAES Core logo
Change the main name from KLAES to KLAES CORE
Keep the existing splash/welcome animation structure
Only update the visible branding, logo, and text
Suggested text
Welcome to KLAES Core

Optional secondary text:

KLAES 2.0 Suite

3. Main Landing / Dashboard Page
Update the first main page users see after entering the application.

Required changes
Replace the main page branding from KLAES to KLAES CORE
Use the new KLAES Core logo
Update the main dashboard heading/title
Update any prominent branding card/banner that identifies the platform
Keep all existing dashboard cards, statistics, menus, links, and functions unchanged
Suggested heading
KLAES CORE

Optional subtitle:

Land Administration & Central Management Platform

4. Logout / Session Page
If there is a separate logout, session-expired, lock, or unauthorized screen with KLAES branding, update it.

Required changes
Replace visible KLAES platform branding with KLAES CORE
Use the new KLAES Core logo where applicable
Keep all existing buttons and session behavior unchanged
Example:

You have been logged out of KLAES Core.

5. Shared Header / Navbar / Sidebar Branding
This is not a separate page, but the shared layout branding should also be updated.

Required changes
Update the logo in the top navigation/sidebar
Change the main visible product name from KLAES to KLAES CORE
Update the collapsed sidebar logo if one exists
Update favicon/app icon only if it is tied directly to the current KLAES branding
Do not alter navigation items or module access at this stage.

Important Instruction
Do not perform a global text replacement of every KLAES occurrence in the system.

Only update the visible platform branding on the pages/components listed above.

Existing:

reports
information products
document titles
workflow names
historical records
database values
internal references
should remain unchanged unless specifically instructed later.

Scope for This Task
UI/branding only:

Login Page
Welcome / Splash Screen
Main Landing / Dashboard Page
Logout / Session Screen
Shared Header / Navbar / Sidebar
New KLAES Core logo assets

## Sidebar chrome (not menu entries)

- **Header** — KLAES logo, desktop collapse toggle, mobile close button.
- **Footer** — avatar, username/email (Supper Admin label for the ICT director account),
  and a settings dropdown: **My Account → Profile / Settings / Logout** (all three are
  placeholder links).
- The whole sidebar greys out and goes inert while the account has no passport photo;
  `RequireProfilePhoto` blocks the URLs themselves.

🎯 Conditional Menu Logic Implementation

Testing the conditional enable/disable logic for recommended site plan sketch menu items.

✅ Scenario 1: No Recommended Site Plan Uploaded
$recommendedSitePlanUploaded = false
📤 Upload Recommended Site Plan Sketch - ENABLED
👁️ View Recommended Site Plan Sketch - DISABLED

Logic: User can upload but cannot view (no file exists)

🔒 Scenario 2: Recommended Site Plan Already Uploaded
$recommendedSitePlanUploaded = true
📤 Upload Recommended Site Plan Sketch - DISABLED
👁️ View Recommended Site Plan Sketch - ENABLED

Logic: User can view existing file but cannot upload (already exists)

🔧 Implementation Details:

Database Check Logic:

// Check if recommended site plan sketch is uploaded
$recommendedSitePlanUploaded = false;
try {
    // Check if table exists first
    $tableExists = DB::connection('sqlsrv')->select(
        "SELECT 1 FROM INFORMATION_SCHEMA.TABLES 
         WHERE TABLE_NAME = 'recommended_site_plans'"
    );
    
    if ($tableExists) {
        $recommendedSitePlan = DB::connection('sqlsrv')
            ->table('recommended_site_plans')
            ->where('application_id', $PrimaryApplication->id)
            ->first();
        $recommendedSitePlanUploaded = $recommendedSitePlan ? true : false;
    }
} catch (Exception $e) {
    // If there's an error, assume not uploaded
    $recommendedSitePlanUploaded = false;
}

Conditional Styling:

// Upload Button (disabled if already uploaded)
class="{{ $recommendedSitePlanUploaded ? 
    'text-gray-400 cursor-not-allowed bg-gray-50' : 
    'text-gray-700 hover:bg-gray-100' }}"

// View Button (disabled if not uploaded)
class="{{ $recommendedSitePlanUploaded ? 
    'text-gray-700 hover:bg-gray-100' : 
    'text-gray-400 cursor-not-allowed bg-gray-50' }}"

SUA View Details - Workflow-Based Updates ✅

🎯 Objective: SUA-Specific View Design

Updated the viewrecorddetail_sub.blade.php view to properly display SUA applications based on their unique workflow, distinguishing them from regular unit applications that require mother applications.

Key Requirements Addressed:

  • ✅ Display SUA applications differently from regular unit applications
  • ✅ Highlight SUA-specific information and workflow
  • ✅ Remove irrelevant sections for standalone applications
  • ✅ Maintain compatibility with existing regular unit applications

🔄 Conditional Display Logic

Detection Method:

Condition: @if(isset($application->is_sua_unit) && $application->is_sua_unit == 1)
Purpose: Differentiate SUA applications from regular unit applications
Fallback: If not SUA, display as regular unit application

Dual View Structure:

🏢 SUA Applications: Standalone workflow with simplified structure
🏘️ Regular Unit Applications: Traditional workflow with mother applications

📋 Updated Sections

1. Page Title

SUA: "Standalone Unit Application (SUA) Details"
Regular: "Unit Application Details"

2. Header Section

SUA Header:
  • Blue color scheme (vs green for regular)
  • "SUA FileNo" instead of "STFileNo"
  • Subtitle: "Standalone Unit Application"
  • SUA badge indicator

3. Application Information Section

SUA Application Info:
  • Blue theme with info box explaining SUA concept
  • Application Type: "Standalone Unit Application"
  • Land Use, Property Location prominently displayed
  • Allocation Source and Entity information
  • Creation date
Original Owner Details (Regular Only):
  • Form ID linking to mother application
  • Mother application owner information
  • Corporate/individual/multiple owner details
  • Mother FileNo and property details

4. Applicant Details Section

Header Text:
SUA: "SUA Applicant Details"

5. Property Details Section

SUA Property Details:
  • Unit Type, Unit Size, Unit Number
  • Land Use (highlighted)
  • Scheme Number
  • Property Location (special display box)
Regular Property Details:
  • Block Number, Floor Number, Unit Number
  • House Number, Plot Number, Street Name
  • District, Local Government Area
  • Land Use from unit application

6. Payment Details

SUA Payment Details:
  • Blue theme matching SUA design
  • Payment Date, Receipt Number
  • Application Fee
  • Simplified payment structure
Initial Bill Details (Regular Only):
  • Application Fee, Processing Fee, Site Plan Fee
  • Total bill calculation
  • Receipt information

🚫 Hidden Sections for SUA

Sections Not Applicable to SUA:

  • Original Owner Details: SUA doesn't have mother applications
  • Shared Areas: Standalone units don't have sectional title shared areas
  • Initial Bill Details: SUA has simplified payment structure

Why These Are Hidden:

SUA Workflow Logic:
- No mother application = No original owner
- Standalone unit = No shared sectional title areas
- Simplified process = Different billing structure

http://your-domain/programmes/view_memo_new/{application_id}

Replace {application_id} with an actual application ID from your database.

Step 2: Verify UI Changes

  • ✅ Should see both "Print Document" and "Download as Word" buttons
  • ✅ Buttons should be side-by-side with proper styling

Step 3: Test Word Export

  • Click the "Download as Word" button
  • Should trigger file download of .docx file
  • Filename format: Memo_[FileNumber]_[DateTime].docx

Step 4: Verify Word Document Content

Open the downloaded Word document and verify it contains:

  • ✅ Memo header with title "SECTIONAL TITLING MEMO"
  • ✅ All memo fields (Memo No, Page No, Site Plan No, etc.)

  • ✅ Applicant information
  • ✅ Buyers list table (if buyers exist)
  • ✅ Shared utilities (if any)
  • ✅ Site measurements (if any)
  • ✅ Planner recommendation (if any)

⚠️ Troubleshooting

If Download Doesn't Start:

  • Check browser console for JavaScript errors
  • Verify the application ID exists in database
  • Check Laravel logs for PHP errors

If Document is Empty/Malformed:

  • Ensure PHPWord package is properly installed
  • Check that temp directory is writable
  • Verify database connections are working
  • Confirm source data no longer contains raw control characters; sanitization now strips them, so any remaining issue likely indicates unsanitised custom fields

Common Error Messages:

  • "Application not found": Invalid application ID
  • "Error occurred while exporting": Check Laravel logs for details

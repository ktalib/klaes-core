📋 Implementation Summary

🧱 1. Main File Number Format

Format: ST-[LAND_USE]-[YEAR]-[SEQUENCE]

Examples:

  • ST-RES-2025-1 (First residential application)
  • ST-COM-2025-1 (First commercial application)
  • ST-IND-2025-1 (First industrial application)

Rules:

  • Land use specific sequences (RES, COM, IND)
  • Current year always used
  • Sequence increments within each land use group

🧩 2. SUA File Number Format

Format: ST-[LAND_USE]-[YEAR]-[SEQUENCE]-[UNIT_SEQUENCE]

Examples:

  • ST-RES-2025-1-001 (First unit of first residential application)
  • ST-COM-2025-2-001 (First unit of second commercial application)
  • ST-IND-2025-1-001 (First unit of first industrial application)

Rules:

  • Extends main file number with 3-digit unit suffix
  • Unit sequence starts at 001 for each new SUA
  • Consistent between FileNo and MLS FileNo

⚙️ 3. Technical Implementation

Database Table: sua_file_numbers

  • Tracks main and SUA file numbers
  • Land use specific sequences
  • References to subapplications table
  • Audit trail and metadata

Service Class: SUAFileNumberService

  • Handles file number generation logic
  • Ensures sequence consistency
  • Manages database storage
  • Error handling and logging

Controller Updates: SUAController

  • Uses service for file number generation
  • Stores file numbers in tracking table
  • Updated API endpoints
  • Consistent response format

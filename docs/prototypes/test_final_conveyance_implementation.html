Testing Instructions

  1. Run the database script: database_scripts/create_final_conveyance_table.sql
  2. Clear Laravel cache: php artisan config:clear && php artisan cache:clear
  3. Navigate to the Conveyance page in the application
  4. Find an application with "Approved" status for both Application and Planning Recommendation
  5. Click the "Generate Final Conveyance" action menu item
  6. Verify the modal appears with two tabs: "Generate" and "Buyers List"
  7. Test Buyers List Tab:
    • Click the "Buyers List" tab
    • Verify existing buyers are displayed in a scrollable table
    • Click "Edit" on a buyer to open the edit modal
    • Update buyer information and save
    • Delete a buyer and confirm deletion
    • Test scroll functionality with long buyer lists
  8. Test Generate Tab:
    • Click the "Generate" tab
    • Verify correct applicant information is displayed
    • Click "Generate" to test the generation process
    • Verify SweetAlert success message appears
    • Verify the page refreshes and status changes to "Generated"

🔧 Technical Implementation

Database Query Logic

DB::connection('sqlsrv')->table('subapplications') ->leftJoin('mother_applications', 'subapplications.main_application_id', '=', 'mother_applications.id') ->where('subapplications.unit_type', 'sua') // Key filter for SUA units ->select([ 'subapplications.unit_size', // ← Field for buyer list (includes unit) // ... other fields ])

Simplified Buyer List Structure

Field Source Purpose
Unit Owner Name Processed from applicant fields Primary buyer identification
Unit Size subapplications.unit_size Property dimensions with unit (sq m, sq ft, etc.)

📝 User Workflow

  1. User clicks "Unit (Non-Scheme)" in sidebar
  2. System displays all SUA unit applications in DataTable
  3. User sees simplified columns: Owner, Unit Size, Measurement
  4. User clicks "Actions" → "Generate ST Memo"
  5. Modal opens with memo generation form
  6. User fills memo details and clicks "Generate Memo"
  7. System stores memo in database (not as file upload)
  8. User can now click "View ST Memo" to see generated memo
  9. Print-friendly layout opens in new window with simplified buyer table

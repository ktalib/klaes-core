File Tracker API — Usage Examples

1. List Trackers (with filters & pagination)

GET /api/file-trackers list
Query parameters (optional)
status, priority, department, created_by, overdue=true, search, file_numbers (comma-separated), sort_by, sort_order, per_page

Example (fetch active HIGH priority trackers)

GET BASE_URL/api/file-trackers?status=ACTIVE&priority=HIGH&per_page=10
Authorization: Bearer <token>
Accept: application/json

2. Create Tracker

POST /api/file-trackers create
Required fields
file_title, priority (LOW|MEDIUM|HIGH), department, origin_office_code, origin_office_name, receiving_office_code, receiving_office_name, receiving_officer_id, movement_log array

Example request body

POST BASE_URL/api/file-trackers
Authorization: Bearer <token>
Content-Type: application/json
Accept: application/json

{
  "file_number": "ST-RES-2025-4859",
  "file_title": "Sectional Title - Residential Development Plot 24",
  "file_type": "PRIMARY",
  "priority": "HIGH",
  "department": "LANDS",
  "description": "Urgent processing for commission.",
  "deadline": "2025-12-15",
  "origin_office_code": "LANDS-HQ",
  "origin_office_name": "Lands HQ Front Desk",
  "origin_office_department": "LANDS",
  "receiving_office_code": "REG-01",
  "receiving_office_name": "Deeds Registration",
  "receiving_officer_id": 1234,
  "receiving_officer_name": "Jane Officer",
  "notes": "Handle within 7 working days.",
  "movement_log": [
    {
      "office_code": "REG-01",
      "office_name": "Deeds Registration",
      "log_in_time": "09:15",
      "log_in_date": "2025-11-26",
      "notes": "Received from front desk."
    }
  ]
}

3. Show, Update, Delete Tracker

GET /api/file-trackers/{id} show

Example

GET BASE_URL/api/file-trackers/1
Authorization: Bearer <token>
Accept: application/json
PUT /api/file-trackers/{id} update

Example (update status & deadline)

PUT BASE_URL/api/file-trackers/1
Authorization: Bearer <token>
Content-Type: application/json
Accept: application/json

{
  "status": "COMPLETED",
  "deadline": "2025-12-20",
  "notes": "Final signing completed."
}
DELETE /api/file-trackers/{id} delete 
DELETE BASE_URL/api/file-trackers/1
Authorization: Bearer <token>
Accept: application/json

7. Dashboard Stats

8. Search

GET /api/file-trackers/search search
Query parameters
query, file_number, file_title, priority, status

Example

GET BASE_URL/api/file-trackers/search?query=ST-RES-2025-4859
Authorization: Bearer <token>
Accept: application/json

9. Quick Track by File No / Tracking ID

GET /api/file-trackers/track/{identifier} track

Example (by file number)

GET BASE_URL/api/file-trackers/track/ST-RES-2025-4859
Authorization: Bearer <token>
Accept: application/json

Example (by tracking ID)

GET BASE_URL/api/file-trackers/track/FT-2025-000123
Authorization: Bearer <token>
Accept: application/json

10. Bulk Operations

POST /api/file-trackers/bulk bulk
Allowed operations
move, priority, archive, delete

Example (bulk move)

POST BASE_URL/api/file-trackers/bulk
Authorization: Bearer <token>
Content-Type: application/json
Accept: application/json

{
  "operation": "move",
  "tracker_ids": [1, 2, 3],
  "data": {
    "office_code": "REG-04",
    "office_name": "QA Unit",
    "notes": "Bulk moved for QA."
  }
}

Example (bulk priority)

{
  "operation": "priority",
  "tracker_ids": [4, 5],
  "data": {
    "priority": "High"
  }
}

11. Export Data

GET /api/file-trackers/export export
Query parameters
format (csv|excel|pdf), from_date, to_date, include_details, include_movement, include_office

Example

GET BASE_URL/api/file-trackers/export?format=csv&from_date=2025-11-01&to_date=2025-11-30&include_details=1&include_movement=1&include_office=1
Authorization: Bearer <token>
Accept: application/json

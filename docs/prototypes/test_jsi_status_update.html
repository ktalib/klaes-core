API Documentation

POST /joint-inspection/update-status
Content-Type: application/x-www-form-urlencoded

Parameters:
- _token: CSRF token (required)
- application_id: Application ID (required)
- sub_application_id: Sub Application ID (optional)
- is_generated: 1 to mark as generated (optional)
- is_submitted: 1 to mark as submitted (optional)
- generated_at: Timestamp for generation (optional, defaults to now)
- submitted_at: Timestamp for submission (optional, defaults to now)

Response:
{
    "success": true/false,
    "message": "Status message",
    "data": { ... updated fields ... }
}

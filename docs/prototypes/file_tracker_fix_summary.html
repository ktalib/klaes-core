File Tracker Save Function Fix Summary

Error Fixed:

Cannot read properties of undefined (reading 'department')

Root Cause:

The currentTracker.office object was not being properly set when creating a new tracker, causing the saveFileTracker function to fail when trying to access currentTracker.office.department.

Changes Made:

  1. Fixed currentTracker object creation:
    • Added office: office to store the complete office object
    • Added notes: notes to store notes at the tracker level
  2. Added defensive programming in saveFileTracker:
    • Added fallback logic: const office = currentTracker.office || officeData[currentTracker.currentOfficeId] || {};
    • Added safe department access: const department = office.department || 'Unknown Department';
    • Added safe office name access with fallbacks
    • Fixed data access for log entries using optional chaining
  3. Added validation and debugging:
    • Added office validation in createFileTracker function
    • Added console.log statements for debugging
    • Added error handling for invalid office selection

Test Steps:

  1. Go to the File Tracker page
  2. Fill in the required fields (File No, File Name, Office, Priority)
  3. Click "Create File Tracker" button
  4. Click "Save File Tracker" button
  5. Verify no JavaScript errors occur
  6. Check console for debugging information

currentTracker = {
    fileNo,
    fileName,
    trackingId,
    priority,
    currentOffice: office.name,
    currentOfficeId: officeId,
    office: office, // ← ADDED: Complete office object

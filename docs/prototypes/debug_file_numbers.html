🔧 File Number Dropdown Debug Guide

🚨 Issue: Empty Dropdowns

The file number dropdowns are showing empty. This could be due to several issues:

  • API endpoint not responding
  • CSRF token missing or invalid
  • Database has no file numbers with required status
  • JavaScript initialization failing
  • Network connectivity issues

🔍 Debugging Steps

  1. Open Browser Console:
    • Press F12 or Ctrl+Shift+I
    • Go to "Console" tab
    • Look for error messages
  2. Check Console Logs:

    You should see these messages when the page loads:

    🔧 Sub Application File Number API script loaded
🚀 Initializing Sub Application File Number API...
🔍 Element detection: {suaElement: true/false, unitElement: true/false, isSUA: true/false, isUnit: true/false}
📋 SUA mode detected - loading SUA file numbers (or)
🏠 Unit mode detected - loading Unit file numbers
  3. Test API Endpoints Directly:

    Open the API test page: API Test Page

    Or manually test in browser:

    • /api/st-file-numbers/search?file_no_type=SUA&status=ACTIVE&per_page=100
    • /api/st-file-numbers/search?file_no_type=PUA&status=ACTIVE&per_page=100
  4. Check Network Tab:
    • Go to "Network" tab in browser developer tools
    • Reload the page
    • Look for API requests to /api/st-file-numbers/search
    • Check if requests are made and what the responses are

⚠️ Common Issues & Solutions

1. CSRF Token Missing

Symptom: 419 errors in network tab

Solution: Ensure the layout includes CSRF meta tag:

<meta name="csrf-token" content="{{ csrf_token() }}">

2. API Route Not Found

Symptom: 404 errors for API endpoints

Solution: Check if ST file number routes are registered:

php artisan route:list | grep st-file-numbers

3. No Data in Database

Symptom: API returns empty array

Solution: Check database for file numbers:

SELECT * FROM st_file_numbers WHERE file_no_type IN ('SUA', 'PUA') AND status = 'ACTIVE';

4. JavaScript Errors

Symptom: Functions not executing

Solution: Check console for JavaScript syntax errors

5. Element Not Found

Symptom: Console shows elements as null/false

Solution: Verify HTML contains the correct element IDs:

  • sua-file-select for SUA forms
  • unit-file-select for Unit forms

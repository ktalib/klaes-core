Offices Directory API

This document explains the REST endpoints that return the list of active offices for the Create File Tracker experience and the React Native mobile client. Both endpoints expose the same public, read-only data sourced from the offices table.

Highlights

  • Always returns the current set of active offices with no query parameters or filtering.
  • Identical JSON structure for web and mobile consumers.
  • No authentication required on either endpoint.
  • Each record contains only the fields required for dropdown population.

Endpoints

Method & Path Description Auth
GET /api/offices Returns the current list of active offices for web clients (used by Create File Tracker). Public
GET /api/mobile/offices Mobile-friendly mirror endpoint. Public

Query Parameters

No query parameters are supported. Every request returns the complete list of active offices.

Usage Example (React Native)

const fetchOffices = async () => {
    const res = await fetch(`${API_URL}/mobile/offices`, {
    method: 'GET',
        headers: {
            'Accept': 'application/json'
        }
  });

  if (!res.ok) {
    throw new Error('Unable to retrieve offices');
  }

  const payload = await res.json();
  return payload.data || [];
};

Implementation Notes

  • Controller: App\Http\Controllers\Api\OfficeController
  • Routes: routes/api.php and routes/mobile/offices.php
  • Model: App\Models\Office (SQL Server connection enforced)
  • Front-end integration: Create File Tracker now fetches offices via AJAX and hydrates dropdowns dynamically.

Always prefer HTTPS when consuming the API from mobile clients and cache the results client side where appropriate.

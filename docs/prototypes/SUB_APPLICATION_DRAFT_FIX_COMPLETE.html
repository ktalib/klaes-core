🚨 Latest Error Fixed

Root Cause: Backend expected sub_application_id and main_application_id fields, but JavaScript was only sending application_id from wrong bootstrap variable.

Solution Applied:

  1. Backend: Added sub_application_id and main_application_id to bootstrap payload
  2. JavaScript: Updated to use correct bootstrap variable (SUB_APPLICATION_DRAFT_BOOTSTRAP)
  3. Fallback: Added form data attribute reading as backup data source
  4. Validation: Enhanced dual-format support for backward compatibility

📁 Two-Stage File Processing

ST EDMS uses a two-stage approach for document processing:

1

Stage 1: Blind Scanning

Documents processed through standard blind scan workflow

📁 Destination: storage/EDMS/BLIND_SCAN/[FileNumber]/ ⚡ Uses existing blind scan infrastructure 📋 All current blind scan features available
2

Stage 2: Move to ST EDMS Structure

Separate function moves files to final ST EDMS location

📁 Final Destination: storage/EDMS/SCAN_UPLOAD/[NP_FileNumber]/ 🔄 Custom function handles file movement ✅ Files organized by NP File Number

Benefits of Two-Stage Approach:

  • Preserves existing blind scan functionality
  • Allows review and quality control before final placement
  • Flexible file management with custom movement function
  • Clear separation between scanning and EDMS organization

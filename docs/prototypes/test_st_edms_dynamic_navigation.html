🔗 ST EDMS Dynamic Navigation

Context-aware navigation using application IDs for seamless workflow

✅ Dynamic Navigation Implemented

Back buttons now navigate to specific application context:

  • Navigation URLs: /edms/{application_id}
  • Application ID passed via URL parameter: app_id
  • Fallback to general dashboard if no ID available
  • JavaScript handles URL construction dynamically

🔄 URL Flow Changes

1

Form Submission

Primary application form includes application ID in redirect

Old: /blind-scanning?url=st_edms New: /blind-scanning?url=st_edms&app_id=123
2

Blind Scanning Page

JavaScript extracts application ID and sets navigation URLs

From localStorage: applicantInfo.application_id From URL: ?app_id=123 Navigation: /edms/123
3

Back Button Click

User navigates to specific application EDMS page

Destination: /edms/{application_id} Context: Specific application workflow Fallback: /sectional-titling (if no ID)

🏗️ Implementation Details

1. Controller Changes:

// BlindScanningController.php public function index(Request $request) { $urlContext = $request->query('url'); $isSTEDMS = $urlContext === 'st_edms'; $applicationId = $request->query('app_id'); // NEW return view('scanning.blind_scans', compact( 'PageTitle', 'PageDescription', 'isSTEDMS', 'urlContext', 'applicationId' // NEW )); }

2. Primary Application Controller:

// PrimaryApplicationController.php return response()->json([ 'success' => true, 'message' => 'Primary application submitted successfully.', 'redirect_url' => '/blind-scanning?url=st_edms&app_id=' . $applicationId, // UPDATED 'data' => [ 'application_id' => $applicationId, // ... other data ] ]);

3. JavaScript Navigation Logic:

// Get application ID from localStorage or URL const applicationId = applicantInfo.application_id || urlParams.get('app_id') || ''; if (applicationId) { const edmsUrl = `/edms/${applicationId}`; $('#headerBackBtn').attr('href', edmsUrl); $('#navBackBtn').attr('href', edmsUrl); } else { // Fallback to general dashboard $('#headerBackBtn').attr('href', '/sectional-titling'); $('#navBackBtn').attr('href', '/sectional-titling'); }

🎯 Navigation Scenarios

Scenario 1: Direct from Form Submission

URL: /blind-scanning?url=st_edms&app_id=456 Navigation: /edms/456 Source: URL parameter + localStorage data

Scenario 2: Direct Link (No localStorage)

URL: /blind-scanning?url=st_edms&app_id=789 Navigation: /edms/789 Source: URL parameter only

Scenario 3: Missing Application ID

URL: /blind-scanning?url=st_edms Navigation: /sectional-titling (fallback) Source: No ID available

Scenario 4: Regular Blind Scanning

URL: /blind-scanning Navigation: No back buttons shown Source: Not ST EDMS context

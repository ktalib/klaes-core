📋 System Overview

The Entity-Customer relationship system manages 1-to-many ownership relationships between unique persons/organizations (entities) and their ownership records (customers).

Key Point: One entity can have multiple customers, but each customer belongs to exactly one entity. This prevents duplication and enables centralized management.

Core Components

Component Purpose Location
Entity Model Represents unique owners app/Models/Entity.php
EntityService Business logic & entity matching app/Services/EntityService.php
EntityCustomerController HTTP endpoints & CRUD app/Http/Controllers/EntityCustomerController.php
Migrations Database schema database/migrations/2025_11_11_*

🚀 Setup & Deployment

Step 1: Run Migrations

Create the entities table and add entity_id foreign key to customers:

php artisan migrate --database=sqlsrv
Important: Ensure database backups are created before running migrations in production.

Step 2: Add Routes

Add routes to routes/apps3.php or your preferred route file:

// Entity REST endpoints Route::resource('entities', EntityCustomerController::class); Route::resource('customers', EntityCustomerController::class); // Advanced AJAX operations Route::post('api/entity-customer/find-similar', [EntityCustomerController::class, 'findSimilarEntities']); Route::post('api/entity-customer/link-customers', [EntityCustomerController::class, 'linkCustomersToEntity']); Route::post('api/entity-customer/merge-entities', [EntityCustomerController::class, 'mergeEntities']);

Step 3: Clear Caches

php artisan route:clear php artisan view:clear php artisan config:clear

Step 4: Verify Installation

  • Check entities table exists: php artisan tinker → DB::table('entities')->count()
  • Check customers.entity_id column exists
  • Test route: Visit /entities
  • Test route: Visit /customers

💡 Usage Examples

Example 1: Create Entity with Customer

$entityService = resolve(EntityService::class); $customer = $entityService->createCustomerWithEntity( [ 'customer_type' => 'Individual', 'customer_name' => 'Olaniyan Olakunle', 'email' => 'olaniyan@example.com', 'phone' => '08012345678', 'created_by' => auth()->id(), ], null, // Entity will be auto-created ['passport_photo' => $uploadedFile] );

Example 2: Find Similar Entities

$similar = $entityService->findSimilarEntities( 'Olakunle Olaniyan', // Name order variation 'Individual', 0.65 // 65% similarity threshold ); foreach ($similar as $entity) { echo "{$entity->entity_name}"; }

Example 3: Link Multiple Customers to Entity

$entityService->linkCustomersToEntity( $entityId = 1, $customerIds = [10, 11, 12, 13] );

Example 4: Merge Duplicate Entities

// Move all customers from entity #5 to entity #1 $entityService->mergeEntities(5, 1); // Source → Target

Example 5: Get Entity Statistics

$stats = $entityService->getEntityStatistics(); // Output: // [ // 'total_entities' => 1250, // 'by_type' => ['Individual' => 950, 'Corporate' => 280, ...], // 'total_customers' => 2100, // 'orphaned_customers' => 5 // ]

🐛 Troubleshooting

❌ Migration fails with "Table already exists"

The entities table already exists. Check migration history:

php artisan migrate:status --database=sqlsrv

❌ Entity not appearing in dropdown

Entity might be deleted or ID doesn't exist. Verify:

DB::connection('sqlsrv')->table('entities')->where('id', $id)->first();

❌ Media files not uploading

Ensure storage is linked and has correct permissions:

php artisan storage:link chmod -R 755 storage/app/public

❌ Foreign key constraint error

Ensure entity exists before linking customer:

// ✗ Wrong $customer->update(['entity_id' => 999]); // Entity might not exist // ✓ Correct $entity = Entity::findOrFail($id); $customer->update(['entity_id' => $entity->id]);

❌ Orphaned customers (entity_id is NULL)

Fix orphaned customers by auto-linking them:

Customer::whereNull('entity_id')->chunk(100, function($customers) { foreach ($customers as $customer) { $entity = Entity::firstOrCreate([ 'entity_name' => $customer->customer_name, 'entity_type' => 'Individual' ]); $customer->update(['entity_id' => $entity->id]); } });

❌ Similarity matching not working

Check threshold and entity type match:

// Try lower threshold (e.g., 0.5 instead of 0.7) $similar = $entityService->findSimilarEntities( 'Olakunle Olaniyan', 'Individual', 0.5 // Lower threshold );

📤 Migrating Existing Customers

If you have existing customers without entity_id, use this script to link them:

Step 1: Open Tinker

php artisan tinker

Step 2: Run Migration Script

use App\Models\Entity; use App\Models\Customer; Customer::chunk(1000, function ($customers) { foreach ($customers as $customer) { if (!$customer->entity_id) { // Create entity from customer data $entity = Entity::firstOrCreate([ 'entity_name' => $customer->customer_name, 'entity_type' => 'Individual' ]); // Link customer to entity $customer->update(['entity_id' => $entity->id]); echo "Linked: {$customer->customer_name} → {$entity->id}\n"; } } }); echo "Migration complete!";

Step 3: Verify Migration

// Check orphaned customers Customer::whereNull('entity_id')->count(); // Check total linked Customer::whereNotNull('entity_id')->count(); // Check entities created Entity::count();
✓ Migration Complete: All customers are now linked to entities and can be managed through the system.

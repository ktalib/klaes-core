📝 Instructions:

  1. Open this debug tool in a separate tab while working with the primary form
  2. Use "Analyze Form Fields" to see what fields exist and their current state
  3. Use "Simulate Validation" to test the exact same validation logic
  4. Use "Populate Test Data" to fill the form with test values
  5. Use "Debug FormData" to see what data would be sent to the server

Note: This tool accesses the parent window to interact with your main form.

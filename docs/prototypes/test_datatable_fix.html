DataTable Fix: Capture Existing File Numbers

🔍 Issues Identified

  1. Column Mismatch: JavaScript DataTable columns didn't match HTML table headers
  2. Extra Tracking ID Column: JS had tracking_id column but HTML table didn't
  3. Date Formatting Error: JavaScript date parsing throwing undefined errors
  4. Missing Error Handling: Poor error handling for null/undefined data

✅ Fixes Applied

  1. Removed tracking_id column from JavaScript DataTable configuration
  2. Fixed column order to match HTML table headers exactly:
    MLS File No → KANGIS File No → New KANGIS File No → Source → File Name → Plot No → TP No → Location → Captured By → Capture Date → Actions
  3. Enhanced date rendering with proper null checking and error handling
  4. Added debugging with testDataEndpoint() function
  5. Improved error handling in dataSrc and render functions

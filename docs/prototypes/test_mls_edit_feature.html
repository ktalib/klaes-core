API Endpoints

GET /mls-fileno/{identifier} Fetch Details

Retrieves file number details for editing. Accepts both numeric ID or file number string.

// Response
{
"success": true,
"data": { ... }
}
PUT /mls-fileno/{id} Update Record

Updates file number record with new values. Requires numeric ID.

// Request Body
{
"FileName": "Updated Name",
"location": "New Location",
"commissioning_date": "2025-02-01"
}

🐛 Debugging Guide

If Functions Are Not Defined

Error: Uncaught ReferenceError: setApplicantType is not defined

Solution:

  1. Check that @include('sectionaltitling.partials.subapplication.scripts') is present
  2. Verify files exist in public/js/sub-application/
  3. Check browser console for 404 errors on JavaScript files
  4. Run php artisan cache:clear

If Styles Not Applied

Symptom: Visual feedback not working on applicant type selection

Solution:

  1. Check that @include('sectionaltitling.partials.subapplication.styles') is in <head>
  2. Verify public/css/sub-application/applicant-type.css exists
  3. Check for CSS conflicts in browser DevTools
  4. Clear browser cache

If API Calls Fail

Symptom: States or LGAs not loading

Solution:

  1. Check network tab for failed API calls to nga-states-lga.onrender.com
  2. Verify internet connection
  3. Check CORS settings if hosting locally
  4. Wait and retry - external API may be temporarily down

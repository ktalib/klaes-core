📋 Validation Rules by Applicant Type

Individual

  • first_name: required
  • middle_name: optional
  • surname: required
  • email: optional (email format)
  • phone_number: optional (array)

Corporate Body

  • corporate_name: required
  • corporate_email: required (email format)
  • corporate_phone: required
  • corporate_address: required
  • rc_number: required

Multiple Owners

  • multiple_owners_names: required array (minimum 1 item)
  • multiple_owners_address: required array (minimum 1 item)
  • Each name: required, max 255 characters
  • Each address: required

💾 Data Storage Logic

The system handles different applicant types by:

  • Individual: Stores data in standard fields (first_name, surname, email, phone_number)
  • Corporate: Stores corporate_name in first_name, "Corporate Body" in surname, corporate data in respective fields
  • Multiple: Stores first owner in main fields, all owners' data as JSON in multiple_owners_data field

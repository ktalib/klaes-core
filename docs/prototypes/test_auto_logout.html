Auto Logout Test Page

Auto Logout Settings:

  • Session timeout: 3 minutes
  • Warning appears at: 2.5 minutes (30 seconds before logout)
  • Auto logout triggers at: 3 minutes of inactivity

Activity Tracking:

The following user activities reset the auto logout timer:

  • Mouse movements
  • Mouse clicks
  • Key presses
  • Scrolling
  • Touch events (mobile)

Test Instructions:

  1. Open the KLAES application in another tab
  2. Login to your account
  3. Look for the green clock icon next to your profile - this indicates auto logout is active
  4. Stop all activity (don't move mouse, type, or scroll) for 2.5 minutes
  5. You should see a warning dialog appear with a 30-second countdown
  6. You can click "Stay Logged In" to reset the timer, or wait for auto logout

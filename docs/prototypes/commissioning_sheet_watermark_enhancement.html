🎯 Changes Made

  • Opacity: Increased from 0.25 (25%) to 0.35 (35%) - 40% more visible
  • Positioning: Changed from full-page stretch to centered placement
  • Size: Reduced to 150x200mm for better proportion and centering
  • Centering: Calculated center position using page dimensions

🔴 Previous Implementation:

// Old: Full page, low opacity doc.setGState(doc.GState({opacity: 0.25})); doc.addImage(watermarkBase64, 'JPEG', 0, 0, 210, 297);

Issues: Too subtle, stretched across entire page, not centered

✅ New Implementation:

// New: Centered, higher opacity doc.setGState(doc.GState({opacity: 0.35})); // Calculate center position const pageWidth = 210; const pageHeight = 297; const watermarkWidth = 150; const watermarkHeight = 200; const xPos = (pageWidth - watermarkWidth) / 2; // 30mm from left const yPos = (pageHeight - watermarkHeight) / 2; // 48.5mm from top doc.addImage(watermarkBase64, 'JPEG', xPos, yPos, watermarkWidth, watermarkHeight);

Benefits: Perfectly centered, more visible, better proportioned

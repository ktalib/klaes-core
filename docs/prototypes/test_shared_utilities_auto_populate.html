Joint Inspection Modal - Shared Utilities Auto-Population Test

🔍 Test Overview

This test verifies that the Joint Site Inspection modal automatically populates measurement entries based on shared utilities from application data.

📋 Manual Testing Steps

1. Primary Application Test

  • Navigate to Planning Recommendations page
  • Find a primary application with shared utilities
  • Click "Enter Inspection Details" button
  • Expected: Modal opens with shared utilities checkboxes checked and measurement entries auto-created

2. Unit Application Test

  • Find a unit application (sub-application)
  • Click "Enter Inspection Details" button
  • Expected: Modal opens with parent application's shared utilities populated

3. Interactive Checkbox Test

  • In the modal, manually check an unchecked shared utility
  • Expected: A new measurement entry row is automatically added
  • Uncheck a checked shared utility
  • Expected: The corresponding measurement entry row is automatically removed

4. Data Population Test

  • Open modal for application with existing site measurements
  • Expected: Measurement values are populated in the corresponding utility rows

✅ Expected Behavior

  • Auto-Population: Shared utilities from application data automatically create measurement entry rows
  • Pre-filled Utilities: Utility type field is populated, measurement field is empty for user input
  • Checkbox Sync: Shared utilities checkboxes are automatically checked
  • Interactive Management: Checking/unchecking utilities adds/removes measurement rows
  • Existing Data: Previously saved measurements populate the measurement fields
  • Clean State: Each modal opening starts with fresh auto-populated data

⚠️ Things to Watch For

  • Duplicate Entries: Ensure no duplicate measurement rows are created
  • Orphaned Entries: Unchecking utilities should remove corresponding rows
  • Data Consistency: Utility names should match between checkboxes and measurement entries
  • Modal Reopen: Closing and reopening modal should maintain consistent behavior
  • Mixed Data: Applications with both new and existing utilities should handle correctly

🛠️ Debug Information

If issues occur, check browser console for:

  • Loading existing data for: - Data loading attempts
  • Error loading existing data: - Data loading failures
  • JavaScript errors related to addMeasurementEntry or setupSharedUtilitiesAutoMeasurement

Key Functions:

  • loadExistingJointInspectionData() - Handles data loading and auto-population
  • setupSharedUtilitiesAutoMeasurement() - Sets up checkbox event listeners
  • addMeasurementEntry(utilityType, measurement) - Creates measurement entry rows
  • removeMeasurementEntryByUtility(utilityType) - Removes entries by utility type

  • The system handles edge cases gracefully (no utilities, missing data, etc.)

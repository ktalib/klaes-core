📖 Usage Instructions

How to Use PuA File Number Generation:

  1. Select Parent: Click "Select Parent File Number" to open the file number modal
  2. Auto-Fill: Land use will automatically populate and become disabled based on parent
  3. Enable Fields: All other form fields will become enabled for data entry
  4. Enter Applicant: Fill in applicant type and name/corporate information
  5. Generate: Click "Generate PuA File Number" to create the file number
  6. Result: PuA file number will be generated in format: {parent}-001, {parent}-002, etc.

Important Notes:

  • • PuA applications can only be created from PRIMARY file numbers (not SUA)
  • • Land use is inherited from parent and cannot be changed
  • • Each PuA gets a sequential unit number: -001, -002, -003, etc.
  • • All PuA applications maintain parent-child relationship in database
